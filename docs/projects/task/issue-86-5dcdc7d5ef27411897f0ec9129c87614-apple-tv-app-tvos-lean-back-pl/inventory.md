# Bestandsaufnahme: Apple TV-App (tvOS) — Lean-back-Player via .NET for tvOS

Inventar des Ist-Stands zur Anforderung `requirement.md` (Issue #86): welche plattformneutralen Schichten, Dienste, Modelle und der iOS-Deployment-Pfad existieren, und welchen Ausgangszustand die Tests haben. Keine Planung, keine Implementierungsvorschläge.

## Zusammenfassung

- **Projektstruktur:** 8 Projekte im Root (kein `src/`): `VideoPlayer.Mvu`, `VideoPlayer.Storage`, `VideoPlayer.ApiClient` (alle `net10.0`, plattformneutral, keine MAUI-Abhängigkeit), `msTools.DeveloperApi` (`net10.0`, `#if DEBUG || DEV_API`), `msTools.DeveloperApi.Maui` + `VideoPlayer.Maui` (MAUI-Appschicht, `net10.0-android/ios/maccatalyst/windows`), `VideoPlayer.Maui.Tests` (xunit.v3, `net10.0`), `VideoPlayer.E2E.Tests` (FlaUI, `net10.0-windows`). **Kein tvOS-Projekt vorhanden.**
- **MVU-Kern wiederverwendbar:** `MvuHost` (serialisiert `DispatchAsync` über Gate) + `AppUpdate.Update` (reine Funktion, ~135 Messages → `AppModel` + ~75 `AppEffect`-Records) + `IAppEffectHandler` als einzige Plattform-Anlaufstelle. MAUI-Implementierung: `ShellAppEffectHandler` (2396 Zeilen).
- **Wiederverwendung belegt:** Pairing (`DevicePairingClient` exchange/bootstrap, `PairingCrypto` ECDH P-256/AES-256-GCM, `ClientGate`-Geräte-Token), Discovery (`ServerDiscoveryService`: mDNS via Zeroconf + UDP-Broadcast `:5001`), Serververwaltung (`KnownServersService`, `ServerAddress`, `AuthSessionService`, `DeviceTokenService`), Startseite (`HomeListService`, `cached_lists`, saisonale Genres), Browsing/Suche (`SourceBrowserService`, `api/items` mit `search`-Parameter), Detailseiten (`MediaDetailsService` inkl. Offline-Snapshot via `ShowDetailsCache`), Wiedergabe (`PlaybackSourceService`, `PlayerState` mit `EndWindowStreak`/Playlist-Kontext, `ProgressReportService` + `pending_progress`-Outbox, `UpcomingEpisodesService` + Playlist-`advance`), Playlists lesend (`PlaylistService`: `api/playlists`, `…/public`, `entries/paged`, `play`-Endpunkte — der Schreibbereich existiert ebenfalls und wäre unverdrahtet zu lassen), Downloads (`DownloadService` mit Manifest `download_manifest`, Quota `DownloadQuotaGb`, Ablaufdatum `ExpiresAtUtc`/`DownloadRetentionDays`, Reconcile inkl. `missing_file`-Korrektur), Einstellungen (`AppSettings`/`AppSettingsService` + `ISettingsStore`/`ISecretStore`-Abstraktion).
- **Für tvOS fehlende Trigger/Lücken (Feststellung):** Der Download-Abgleich (`DownloadService.ReconcileAsync`) wird heute nur über `ResumeDownloadsEffect` (App-Start nach Verbindungsaufbau, Online-Rückkehr) und `LoadDownloadsEffect` (Öffnen der Downloads-Seite) ausgelöst — **kein Lebenszyklus-/Aktivierungs-Trigger** (`window.Resumed` dispatched nur `HomeListsReloadRequestedMessage`). Es gibt keine Spur-/Untertitelwahl (kein `AVMediaSelectionGroup`-Äquivalent; Player ist MAUI `MediaElement`). `IDownloadBackend` existiert als Abstraktion (`HttpDownloadBackend` plattformneutral, `IosBackgroundDownloadBackend` via `NSUrlSession`, `#if IOS`).
- **CI/Deployment:** iOS-Pfad vollständig vorhanden — Composite-Action `.github/actions/package-ios` (SDK-Band-Pin `10.0.100` via `global.json`, Workload-Rollback `microsoft.net.sdk.ios`, Keychain-Import, `dotnet publish -f net10.0-ios -r ios-arm64 -p:ArchiveOnBuild`, iTMSTransporter-Upload), Jobs `build-ios`/`package-ios` in `staging-merge.yml` + `main-merge.yml` (Gate `vars.IOS_SIGNING_ENABLED` + `released`), Secrets `IOS_*`, lokales Skript `scripts/iOS-Deployment.ps1`. tvOS-Pendant existiert nicht; keine `tvos`-Workload installiert.
- **Test-Ausgangszustand:** Unit/Contract-Suite `VideoPlayer.Maui.Tests`: **1440 erfolgreich, 0 Fehler** (Exit 0). E2E-Suite `VideoPlayer.E2E.Tests` (FlaUI, Windows): **71 erfolgreich, 3 Fehlgeschlagen** (Exit 1) — `PlaylistPlaybackTests.StreamFailure_AdvancesToNextPlaylistEntry` (App-Absturz `0xC000027B`) sowie `SourceSearchTests.SubmitViaEnter_FiltersFromFirstPage` und `SubmittedText_RemainsVisibleAfterReturn` (Timeouts). Details: [inventory/tests.md](inventory/tests.md).
