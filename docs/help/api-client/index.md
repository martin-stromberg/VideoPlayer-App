# Server-API-Client

Plattformneutraler clientseitiger Zugriff auf die öffentliche HTTP-API der Serveranwendung „VideoPlayer": Anmeldung, Erreichbarkeitsprüfung, Quellen, „Neu im Programm", Weiterschauen, Favoriten, Mediennachschlagen und Bildabrufe — mit fester Wiederholungsstrategie und automatischer Token-Erneuerung.
